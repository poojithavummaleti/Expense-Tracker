# 💰 Expense Tracker

## Description
This is a simple Expense Tracker web application built using HTML, CSS, and JavaScript. It helps users to manage their income and expenses easily.

##  Features
- Add income and expenses
- Automatic balance calculation
- Delete transactions
- Data stored using localStorage (persists after refresh)
- Simple and clean user interface

##  GitHub Repository
https://github.com/poojithavummaleti/expense-tracker

##  Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Enter description (e.g., salary, food, rent)
2. Enter amount:
   - Positive value → Income
   - Negative value → Expense
3. Click on **Add**
4. Balance will update automatically
5. Click **X** to delete any transaction

## Project Structure
- index.html → Structure of the app
- style.css → Styling
- script.js → Functionality

##  Output
- Displays balance
- Shows list of transactions
- Color indication:
  - Green → Income
  - Red → Expense
